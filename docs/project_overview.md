# CareFlow Project Overview

## Problem Statement
Hospital administrators may struggle to identify which sequences of activities contribute to delays in patient journeys. Average waiting-time metrics alone may not reveal the underlying process bottlenecks.

## Proposed Solution
CareFlow uses process mining and timestamped simulated hospital event logs to reconstruct patient journeys, analyze transitions between activities, identify potential bottlenecks, and examine deviations from an expected pathway.

## Project Objectives
- Generate and validate simulated hospital event data.
- Analyze activity sequences and transition times.
- Discover process flows and potential bottlenecks.
- Check deviations from an expected clinical pathway.
- Present analytical findings through a Power BI dashboard.

## Project Scope
The project covers data generation, data quality validation, SQL-based analysis, process discovery, conformance checking, and dashboard development.

## Expected Outcomes
- A validated simulated event log.
- Process-flow and transition-time analysis.
- Identification of transitions requiring further investigation.
- Conformance analysis results.
- A dashboard and supporting project documentation.

## Data Limitations
The analysis uses simulated data rather than real hospital records. Therefore, identified patterns demonstrate the analytical workflow and do not establish actual hospital performance or clinical outcomes.
